Module 1 Note: The shell and your first script

What is the shell?
The shell reads the commands you type. Bash(Bourne Again Shell) is the most common shell. A script is a text file of commands that bash runs from top to bottom.

Common mistakes:
Forgetting chmod +x gives "Permission denied".
Leaving out ./ gives "command not found".
Leaving out $(...) prints the command name instead of its result.
