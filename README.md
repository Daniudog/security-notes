# Security Notes

My working notes as I master offensive security.
This is a logbook, not a tutorial. I write things down to
understand them, and I keep the parts where I got stuck.

## Contents

- `linux/` : Linux fundamentals, filesystem, permissions, processes
- `bash/` : scripts I've written while learning, with notes on what broke
- `portswigger/` : Web Security Academy lab writeups
- `CTFs/` : coming soon.


## Format

Every lab writeup follows the same shape:

1. What the lab asked for
2. What I tried first
3. Why it failed
4. What actually worked
5. The underlying flaw, in my own words

Step 3 is the point of this repo.
